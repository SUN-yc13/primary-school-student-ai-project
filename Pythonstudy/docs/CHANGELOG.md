# 变更日志

所有重要的版本变更都记录在此文件中。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/)，
版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

---

## [2.0.0] - 2026-08-29

### 新增
- 题库难度分级：`easy` / `medium` / `hard` 三档，考试时可筛选
- 错题本功能：答错的题自动收录，记录错误次数和最近错误时间
- 错题回顾模式：从错题本抽题重做，答对后自动移除
- 考试历史记录：自动保存日期、难度、题量、得分、正确率、错题数
- 历史记录查看：主菜单可查看历次考试成绩与平均正确率
- 题目管理工具增加题库统计功能（按文件和难度统计数量）
- 完整文档体系：README、题库格式规范、维护指南、变更日志
- `.gitignore` 文件，符合 GitHub 项目规范
- 题库扩充至 90 道（简单 30 + 中等 30 + 困难 30）

### 变更
- 题库格式从 6 字段升级为 7 字段（增加难度字段）
- 主程序从单屏考试升级为主菜单架构（考试/错题/历史/退出）
- 题库文件从单一 `python_basics.txt` 拆分为三个难度文件
- 数据文件统一存放于 `data/` 目录（JSON 格式）
- 版本号从 `VERSION` 文件统一管理

### 技术细节
- 数据持久化采用 JSON，支持中文（`ensure_ascii=False`）
- 错题去重基于题目文本匹配，重复答错累计次数
- 难度筛选在题库加载时完成，不影响随机抽取逻辑

### 兼容性
- v1.0 的题库格式（6 字段）**不兼容** v2.0，需在每行开头添加难度字段
- v1.0 的 `add_questions.py` 导入格式需同步升级

## [1.0.0] - 2026-08-29

### 新增
- 初始版本发布
- 支持 3 / 5 / 20 / 50 / 100 道题随机抽取考试
- 内置 30 道 Python 基础单选题
- 提供 `add_questions.py` 题目增加工具（单条添加 + 批量导入）
- 考试结束后按 ESC 退出，窗口不自动关闭
- 基础项目说明文档（README.txt）
- VERSION 版本号文件

- `Deprecated` — 即将移除的功能
- `Removed` — 已移除的功能
