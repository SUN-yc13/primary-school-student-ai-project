## [2.1.0] - 2026-08-30

### 新增
- 考试计时功能：自动记录考试用时，展示几分几秒和平均每题用时
- 历史记录增加 `duration_seconds` 字段
- 题目ID字段：题库格式从7字段升级为8字段，每道题有唯一ID（E/M/H + 3位序号）
- 错题本记录增加 `id` 字段，用于精确去重
- 题库扩充至120道（简单40 + 中等40 + 困难40），新增30道覆盖文件操作、异常处理、模块导入、字符串方法等盲区
- 题目管理工具增加答案分布统计（每个文件和总计的 A/B/C/D 数量）
- 批量导入增加文件大小检查（>10MB拒绝）和UTF-8编码检测
- 原子写入：数据保存先写临时文件再替换，原文件自动备份为 `.bak`
- 题库不足保护：选择题量超过题库时友好提示，不崩溃
- `get_version()` 函数：从 VERSION 文件动态读取版本号
- MIT LICENSE 文件

### 变更
- 答案分布均匀化：全局A/B/C/D各30道，每个难度内各10道（原B占53.3%，easy的D=0，medium的C=0）
- 错题去重键从题干文本改为题目ID，避免同题干不同答案误合并
- 历史记录ID从 `len(history)+1` 改为毫秒时间戳，避免删除记录后ID重复
- 历史记录展示序号改用 `enumerate` 生成，不再用记录ID
- 7道题跨难度移动：4道从easy移到medium，3道从hard移到medium
- `add_questions.py` 的 `validate_line()` 支持8字段，7字段时自动生成ID
- 主菜单版本号从硬编码改为动态读取 VERSION 文件

### 修复
- 修复选100题模式时 `random.sample` 因题库不足崩溃的问题
- 修复 `main.py` 中未使用的 `import sys`
- 修复 `add_questions.py` 中未使用的 `import glob`

### 技术细节
- 数据写入采用原子操作（tmp + os.replace），防止写入中断导致数据损坏
- 每次保存自动创建 `.bak` 备份文件
- 题目ID规则：easy用E001~E040，medium用M001~M040，hard用H001~H040

### 兼容性
- v2.0 的题库格式（7字段）**不兼容** v2.1，需在每行末尾添加题目ID字段
- v2.0 的历史记录和错题本数据可自动兼容（新增字段有默认值）

## [2.0.0] - 2026-08-29

### 新增
- 题库难度分级：`easy` / `medium` / `hard` 三档，考试时可筛选
- 错题本功能：答错的题自动收录，记录错误次数和最近错误时间
- 错题回顾模式：从错题本抽题重做，答对后自动移除
- 考试历史记录：自动保存日期、难度、题量、得分、正确率、错题数
- 历史记录查看：主菜单可查看历次考试成绩与平均正确率
- 题目管理工具增加题库统计功能（按文件和难度统计数量）
- 完整文档体系：README、题库格式规范、维护指南、变更日志
- `.gitignore` 文件，符合 GitHub 项目规范
- 题库扩充至 90 道（简单 30 + 中等 30 + 困难 30）

### 变更
- 题库格式从 6 字段升级为 7 字段（增加难度字段）
- 主程序从单屏考试升级为主菜单架构（考试/错题/历史/退出）
- 题库文件从单一 `python_basics.txt` 拆分为三个难度文件
- 数据文件统一存放于 `data/` 目录（JSON 格式）
- 版本号从 `VERSION` 文件统一管理

### 技术细节
- 数据持久化采用 JSON，支持中文（`ensure_ascii=False`）
- 错题去重基于题目文本匹配，重复答错累计次数
- 难度筛选在题库加载时完成，不影响随机抽取逻辑

### 兼容性
- v1.0 的题库格式（6 字段）**不兼容** v2.0，需在每行开头添加难度字段
- v1.0 的 `add_questions.py` 导入格式需同步升级

## [1.0.0] - 2026-08-29

### 新增
- 初始版本发布
- 支持 3 / 5 / 20 / 50 / 100 道题随机抽取考试
- 内置 30 道 Python 基础单选题
- 提供 `add_questions.py` 题目增加工具（单条添加 + 批量导入）
- 考试结束后按 ESC 退出，窗口不自动关闭
- 基础项目说明文档（README.txt）
- VERSION 版本号文件
