# 题库格式规范

本文档详细说明题库文件的格式要求，供人工编写和 AI 生成题目时参考。

---

## 一、文件基本要求

| 项目 | 要求 |
|---|---|
| 文件类型 | 纯文本 `.txt` |
| 编码 | **UTF-8**（必须，否则中文乱码） |
| 换行符 | LF 或 CRLF 均可 |
| 存放位置 | `questions/` 目录下 |
| 文件名 | 建议 `主题_难度.txt`，如 `python_easy.txt`、`python_web.txt` |

---

## 二、行格式

每行一道题，**7 个字段**，用英文竖线 `|` 分隔：

```
难度|题目|选项A|选项B|选项C|选项D|正确答案
```

### 字段详解

#### 1. 难度（第 1 字段）

| 取值 | 含义 | 适用场景 |
|---|---|---|
| `easy` | 简单 | 语法基础、常识性问题，初学者应掌握 |
| `medium` | 中等 | 需要理解概念、有一定编程经验 |
| `hard` | 困难 | 深入原理、高级特性、易混淆点 |

- 必须**全小写**
- 只能取以上三个值之一

#### 2. 题目（第 2 字段）

- 不能为空
- 建议为完整的问句或陈述
- 题干中如需引用代码，直接写文本即可，不需要 Markdown 格式
- 题干中**不要包含竖线 `|`**，否则会被误判为字段分隔符

#### 3-6. 选项 A-D（第 3-6 字段）

- 四个选项都不能为空
- 建议选项长度相近，避免明显的"长短提示"
- 正确答案随机分布在 A/B/C/D 中，不要固定位置
- 选项中**不要包含竖线 `|`**

#### 7. 正确答案（第 7 字段）

- 取值为 `A`、`B`、`C`、`D` 之一
- 大小写均可，程序自动转大写
- 必须与四个选项中的某一个对应

---

## 三、注释与空行

- 以 `#` 开头的行为**注释行**，程序完全忽略
- 空行（含全空格行）被忽略
- 建议每个题库文件开头写注释，说明题库主题和格式

示例文件头：

```
# Python 基础题库 (easy)
# 格式：难度|题目|A|B|C|D|答案
# 最后更新：2026-08-29
```

---

## 四、完整示例

```
# Python 中级题库
# 格式：难度|题目|A|B|C|D|答案

medium|Python 中 *args 的作用是？|接收任意关键字参数|接收任意位置参数|接收一个元组|接收一个字典|B
medium|以下哪个是生成器表达式？|[x for x in range(3)]|(x for x in range(3))|{x for x in range(3)}|<x for x in range(3)>|B
medium|Python 中深拷贝使用哪个函数？|copy.copy()|copy.deepcopy()|copy()|clone()|B
```

---

## 五、校验规则

程序加载题库时会逐行校验，以下情况会被**跳过并警告**：

1. 字段数不等于 7
2. 难度不是 `easy`/`medium`/`hard`
3. 正确答案不是 A/B/C/D
4. 题目内容为空

可以用以下命令快速检查题库统计（含各难度数量）：

```bash
python add_questions.py stats
```

## 六、编写建议

### 题目质量

- 一道题只考一个知识点
- 题干清晰无歧义
- 错误选项要有迷惑性，不能明显荒谬
- 避免"以上都对"/"以上都错"这类选项（除非刻意考察）

### 难度把控

- **easy**：看到题就能答，考察记忆和基础语法
- **medium**：需要思考或写代码推演，考察理解和应用
- **hard**：考察原理、边界情况、易混淆概念

### 分布均匀

- 每个难度的题目数量建议不少于 20 道
- 正确答案在 A/B/C/D 中尽量均匀分布
- 知识点覆盖全面，避免某一类题目过多

---

## 七、AI 生成题目提示词模板

如需用 AI 批量生成题目，可使用以下提示词：

```
请生成 Python [难度] 级别的单选题，共 N 道。
要求：
1. 每行格式：难度|题目|选项A|选项B|选项C|选项D|正确答案字母
2. 难度字段填 easy/medium/hard
3. 覆盖 [指定知识点范围]
4. 四个选项要有迷惑性，正确答案随机分布
5. 不要包含竖线 | 字符
6. 只输出题目行，不要输出解释或其他文字
```
